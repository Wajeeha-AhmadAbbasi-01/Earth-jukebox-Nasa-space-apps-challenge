Method / reproducibility

How it works

Each route reads a checked-in NASA SVS preview and a deterministic, versioned image-proxy timeline. The browser maps rendered brightness to frequency and display colour to stereo pan. The sound is an artistic, image-derived mapping, not calibrated NASA measurements.

01

Acquire once
Official previews are downloaded by the controlled script, checksum-recorded, and served locally during playback.

02

Extract safely
Equal-width preview strips produce brightness, colour, low-signal and unclassified-share proxies.

03

Sonify explicitly
Web Audio starts only after Play. The shared clock drives seek, transport, volume, mute and status updates.

Access / microphone is optional

Accessibility

The core journey is keyboard-operable without voice recognition or microphone permission. Every transport control has a semantic label, and playback state is announced through the status region. The sound is an artistic, image-derived mapping, not calibrated NASA measurements.

Keyboard navigation works without microphone access. Voice commands start only when requested.

Voice

Voice commands
Try “play ocean”, “pause”, “describe”, “next dataset”, “faster”, “mute”, or “stop listening”.

Methodology / provenance

What this shell is allowed to show

Earth Jukebox uses fixed, checked-in official NASA previews and deterministic rendered-pixel features. It does not contain the underlying NASA numerical science files or infer event records, physical units, concentrations, calibrated temperatures, or source chronology.

Verified hereNASA SVS identity, title, preview asset, documented period, and stated provenance.
Still blockedNumerical files, exact schemas, record semantics, units, quality flags, calibrated values, and source chronology.
Security boundaryNo credentials, arbitrary URL fetching, large media download, or raw source data is stored by this UI.
Proxy boundaryAll three experiences operate on local image-derived features. The method does not recover numerical source measurements.
